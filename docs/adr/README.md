# Архітектурні рішення (ADR)

Кожне рішення, яке важко змінити потім, - окремий файл `NNNN-коротка-назва.md`: статус, контекст (з посиланнями на
код і виміри), рішення, наслідки, розглянуті варіанти, як його перевірено. Рішення не видаляються: змінене рішення
отримує новий ADR, а старий - статус «замінено ADR NNNN».

Загальна картина - [`../crossplatform.md`](../crossplatform.md).
